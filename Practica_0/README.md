1. ¿Qué significa programar de forma estructurada?
     Programar de forma estructurada es resolver un problema dividiendolo en partes más pequeñas y organizando el codigo en bloques lógicos y orenados para que sea
     facil de leer, modificar y mantener.

2. ¿Cuáles son las tres estructuras fundamentales de control?
     secuencia, seleccion e iteración

3. ¿Qué ventaja tuvo separar el programa en funciones?
     El programa es facil de entender cada parte del problema y evita que sea demaciado largo.

4. ¿Qué función tendría que modificarse si la calificación mínima aprobatoria cambiara?
    En nuestro programa no tenemos una función o método para evaluar la aprobación, solo se ejecuta dentro del método main, por lo que tendriamos que cambiar el main, especificamente en la estructura de control ( if (promedio >= ...) ).

5. ¿Qué diferencia conceptual observa entre una función y un método?
     Una función es un bloque de código independiente que raliza una tarea específica y no está atada a una clase ni a la estructura de un objeto. Por otro lado, un método es una funcion que pertenece explicitamente a una clase o a un bojeto, teniendo acceso a sus atributos y su estado. En resumen, todo método es una función,m pero no toda función es un método.

6. ¿Qué representa un commit en Git?
     Es como una captura de pantalla del etado de el proyecto en un momentodeterminado.

7. ¿Por qué es preferible realizar varios commits pequeños en lugar de un solo commit al final?
     Facil depuracion y aislamiento de arrores, revision de código, historial claro y descriptivo.
